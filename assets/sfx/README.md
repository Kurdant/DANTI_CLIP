# Sound effects

Depose ici des effets sonores libres de droits (mp3, m4a, wav, ogg, aac, flac).

Utilisation dans le montage (si les SFX sont actives) :
- **Intro** : un effet joue a ~0.05s (impact du hook).
- **Chiffres cles** : un "ding" joue a chaque chiffre important (max 5).

Nomme les fichiers pour guider le choix automatique :
- Intro/impact : `whoosh_impact.mp3`, `boom_start.mp3`, `swoosh_intro.mp3`...
- Ding/chiffres : `ding_pop.mp3`, `tick_click.mp3`, `chime_hit.mp3`...

Sans fichier ici : aucun effet sonore (comportement inchange).

Sources libres : Pixabay Sound Effects, YouTube Audio Library, freesound.org (CC0).
