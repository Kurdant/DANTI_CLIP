# Musiques de fond

Depose ici tes musiques libres de droits (formats : mp3, m4a, wav, ogg, aac, flac).

Le rendu :
- choisit une piste (celle demandee, ou une au hasard si "Aleatoire"),
- la boucle sur toute la video,
- la baisse automatiquement (ducking) quand la voix parle,
- la fond en fin de video.

Sans fichier ici : aucune musique (comportement inchange).

## Ou trouver des musiques libres

- YouTube Audio Library (filtrer "Sans attribution")
- Pixabay Music : https://pixabay.com/music/
- Free Music Archive : https://freemusicarchive.org/
- Incompetech (Kevin MacLeod) : https://incompetech.com/music/royalty-free/
- Uppbeat : https://uppbeat.io/

Verifie toujours la licence : usage commercial autorise, attribution si requise.
